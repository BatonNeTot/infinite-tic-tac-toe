# Infinite Tic-Tac-Toe

Tic-Tac-Toe game implementation for infinite grid with goal to match 5.

## Dependencies

* [raylib](https://github.com/raysan5/raylib)
* [nbnet](https://github.com/nathhB/nbnet)

## Game flow

* Regular Tic-Tac-Toe rules applied:
  * First player chosen randomly
  * Two players go one after another by placing circles or crosses respectively onto the grid
* To win you need to place 5 circles or crosses aligned horizontally, vertically or diagonally

## How to build

At the moment only *Windows* is supported.

Built using ```mingw-w64-clang-x86_64-clang``` from [msys2](https://www.msys2.org/#installation)
